# Laundry Mart
### One Stop Laundry Solution

Laundry Mart is a website where users can book laundry services like dry cleaning, ironing and wash & fold. Users can add services to a cart, fill in their details and receive a confirmation email. Users can also subscribe to our newsletter.

## Features

1. Responsive navigation bar with links to all sections
2. Hero section with heading, description and Book a Service button
3. Achievements section showing 15+ services, 240+ customers and 2+ years of experience
4. Fully functional booking section where users can add and remove services from cart
5. EmailJS integration to send confirmation email to user on booking
6. Form validation for email format and phone number
7. Quality features section showing Premium Services, Quick Support, Hassle Free Delivery and Affordable Prices
8. Newsletter subscription with validation
9. Footer with important links, contact info and social media icons

## Technologies Used

- HTML5
- CSS3
- JavaScript
- EmailJS
- Ionicons

## How to Run

1. Download the project folder
2. Make sure images folder has laundry.jpg inside it
3. Open index.html in any browser
4. No installation needed

## Booking Flow

1. User adds services from the left panel to the cart
2. Cart updates automatically with total amount
3. User fills in Full Name, Email and Phone Number
4. User clicks Book Now
5. If cart is empty a red warning appears
6. If any field is wrong or empty a red warning appears
7. If everything is correct a confirmation email is sent and success message appears
